## What is ConceptForge?

ConceptForge is an open-source, browser-based AI tool that helps researchers — especially non-native English speakers — elevate rough drafts and colloquial notes into rigorous, publication-ready academic text.

### Highlights

🔬 **Three-Level Concept Elevation** — terminology mapping → mechanism reconstruction → theoretical integration & rewriting

🎯 **Discipline Lens** — built-in presets for Management, Sociology, Psychology, Education, CS, and more; fully customizable

🤖 **Multi-LLM Backend** — seamless switching between Google Gemini, OpenAI, and DeepSeek; API keys stay in your browser

📝 **Reviewer 2 Simulator** — get critiqued by a tough AI peer reviewer before real submission

✍️ **Title Workshop** — auto-generate three styles of journal paper titles

🔒 **Privacy-First** — zero server-side data storage; all keys and preferences live in `localStorage`

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:5173` and you're ready to go.
